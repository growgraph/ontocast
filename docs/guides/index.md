# Guides

The guides are organized by task. Find what you want to do below; each guide
covers one job from start to finish and links to the reference for every
setting it uses.

| I want to... | Guide |
|---|---|
| Decide which settings to change | [Configuring OntoCast](configuration.md) |
| Start from a ready configuration for my job | [Recipes](recipes.md) |
| Call OntoCast from my own agent or LangGraph workflow | [Embedding OntoCast in your agent](embedding.md) |
| Tell OntoCast what to focus on in my documents | [Writing user instructions](user_instructions.md) |
| Choose how each part of a document gets its ontology | [Choosing ontology context](ontology_context.md) |
| Validate extracted facts against SHACL shapes | [Validation and SHACL](validation.md) |
| Keep graphs after the process exits | [Triple stores](triple_stores.md) |
| Keep several users' or projects' data apart | [Tenancy](tenancy.md) |
| Avoid paying twice for the same LLM call | [LLM caching](llm_caching.md) |
| Make runs faster or cheaper | [Performance tuning](performance.md) |
| Understand what a run cost and where it struggled | [Reading run telemetry](telemetry.md) |
| Fix output that is missing or wrong | [Troubleshooting](troubleshooting.md) |
